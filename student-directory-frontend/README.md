# Student Directory Frontend

A React frontend built with Vite and React Router that connects to a secure Express and MongoDB backend using JWT authentication.

Debug reference: banana

## Setup and Installation

### Prerequisites
- Node.js installed
- Running Express backend (from Lesson 5) connected to MongoDB Atlas on `http://localhost:3000`

### Installation Steps

1. Clone the repository:
   ```bash
   git clone <YOUR_GITHUB_REPOSITORY_URL>
   cd student-directory-frontend
